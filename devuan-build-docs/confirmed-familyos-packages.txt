## Not found in either architecture's index

- live-config-systemd: does NOT exist as a package in Devuan's daedalus
  archive at all (checked both binary-amd64 and binary-i386). The only
  real live-config variants Devuan ships are: live-config, live-config-doc,
  live-config-runit, live-config-sysvinit. familyos.list.chroot's
  "live-config-systemd-" entry (trailing-dash APT exclusion syntax) is
  therefore excluding a package that was never a real install candidate
  in this Devuan build to begin with - harmless either way (excluding a
  nonexistent package is a no-op for apt), but the exclusion has zero
  effect here specifically because Devuan's own live-config build never
  produced a -systemd flavour package (unlike a straight Debian build,
  where it would be a real alternative live-config could pull in).
